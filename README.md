# AI Resume Matcher & Skill Gap Analyzer

🚀 **Live Demo:** [Try the AI Resume Matcher](https://airesumeproject-jxtf8wcbxw9dpqx7zufjyx.streamlit.app/)

An AI-powered resume analysis application that extracts text and skills from PDF resumes, analyzes job descriptions, calculates job match scores, identifies skill gaps, and provides role and AI-based recommendations.
